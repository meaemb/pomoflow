# PomoFlow — Pomodoro Productivity & Task Manager

PomoFlow is a cross-platform mobile application built with Flutter, designed to help users boost productivity using the Pomodoro technique combined with task management and real-time data synchronization.

---

## About The Project

PomoFlow combines time management with structured task tracking. It allows users to set focus timers, track work sessions, manage daily tasks, and sync their progress seamlessly across devices.

---

## Key Features

* **Pomodoro Timer:** Customisable focus and break intervals to maintain workflow efficiency.
* **Task Management:** Create, categorize, and complete daily tasks linked to timer sessions.
* **Real-time Sync:** Continuous data synchronization across devices powered by Firebase.
* **Cross-Platform:** Native support and responsive UI for both iOS and Android.

---

## Tech Stack

* **Framework:** Flutter (Dart)
* **Backend & Database:** Firebase (Authentication, Firestore)
* **Architecture:** Clean Architecture / BLoC (or Provider) state management

---

## Getting Started

### Prerequisites

* Flutter SDK installed on your system.
* Android Studio or VS Code with Flutter and Dart plugins.
* Configured Firebase project.

### Installation

1. Clone the repository:
   git clone [https://github.com/meaemb/pomoflow.git](https://github.com/meaemb/pomoflow.git)

2. Navigate to the project directory:
   cd pomoflow

3. Install dependencies:
   flutter pub get

4. Run the app:
   flutter run
